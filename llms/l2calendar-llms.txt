# L2Calendar

> L2Calendar is a multilingual Lineage 2 private server listing platform. It tracks upcoming and past server openings across every game chronicle, with filters by chronicle, rates, labels, and opening date. Server owners can publish announcements with optional VIP placement, and players use the calendar to discover servers before they go live.

Site: https://l2calendar.com
Languages: English (root `/`), Spanish (`/es/`), Portuguese (`/pt/`), Russian (`/ru/`)
Tech: Next.js 16 (App Router), React 19, TypeScript, MySQL
Audience: Lineage 2 players looking for private servers; Lineage 2 server administrators publishing openings.

## Core pages

- [Homepage](https://l2calendar.com/): Upcoming Lineage 2 server openings ordered by date, with VIP and standard listings.
- [All servers](https://l2calendar.com/all-servers): Complete server catalog with filters and pagination.
- [Top servers](https://l2calendar.com/all-servers/topservers): Servers with the highest VIP placement.
- [Opening today](https://l2calendar.com/all-servers/today): Servers launching today (UTC-aware).
- [Opening tomorrow](https://l2calendar.com/all-servers/tomorrow): Servers launching tomorrow.
- [Opened yesterday](https://l2calendar.com/all-servers/yesterday): Servers that opened in the last 24 hours.
- [Servers with add-ons](https://l2calendar.com/all-servers/servers-with-add-ons): Servers tagged with custom add-ons.
- [Interlude Plus](https://l2calendar.com/all-servers/interlude-plus): Interlude-based servers with custom features.
