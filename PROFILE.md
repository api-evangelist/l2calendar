# L2Calendar

Multilingual Lineage 2 private server listing platform tracking upcoming and past server openings across every game chronicle, with filters by chronicle, rates, labels, and opening date. Server owners publish announcements with optional VIP placement.

- **Provider:** https://l2calendar.com
- **Documentation:** https://l2calendar.com/llms.txt
- **Base URL:** https://l2calendar.com

- **Public API:** no
- **Agent-native (MCP / llms.txt / skills):** yes

## APIs

- **L2Calendar Agent-Native Content** — Agent-native content surface exposing machine-readable summaries via llms.txt and llms-full.txt for AI assistants and crawlers to help players find Lineage 2 servers. (`https://l2calendar.com`)

> L2Calendar is an agent-native content provider, not an API provider. Only publicly consumable machine-readable interfaces are llms.txt and llms-full.txt (both confirmed live), supported by sitemap.xml and on-page schema.org JSON-LD. No public REST/GraphQL/OpenAPI/AsyncAPI/Postman contract exists. The site's /api/ path is an internal Next.js endpoint (disallowed in robots.txt) and not a consumable public API. No MCP server and no published agent skills. No dedicated docs portal — closest is the llms.txt itself.
